B&B GROUP FINANCE V1
=====================

Como usar:
1. Extraia o ZIP.
2. Abra index.html no Chrome/Edge.
3. Entre como Belo ou Backson.
4. Palavra-passe inicial: 1234.
5. Os dados ficam guardados no navegador deste dispositivo.

Funcionalidades:
- Dois investidores: Belo e Backson.
- Histórico partilhado no mesmo dispositivo/navegador.
- Receitas, despesas e investimentos.
- Descrição obrigatória para despesas.
- Comissão opcional.
- Limite de investimento por investidor.
- Painel de dívidas.
- Meta semanal (sem metas diárias).
- Assistente B&B com alertas, análise simples e motivação.
- Logo oficial B&B Group.

IMPORTANTE:
Esta V1 é um protótipo funcional offline/local. Para Belo e Backson usarem em DOIS telemóveis diferentes com os mesmos dados em tempo real, a próxima versão precisa de um servidor/API + base de dados (por exemplo MySQL/PostgreSQL) e autenticação segura.
